# Система запису до лікаря

### 1. Для чого потрібна ця система: 
Система потрібна для зручного доступу до лікарів, запису на прийом. Можливість віртуальної черги дозволяє приходити на прийом в призначений час, що звільняє від потреби годинами сидіти в лікарні, очікуючи в реальній черзі. Також є можливість швидкої консультації, без потреби йти в лікарню. 

### 2. Коротко описуючи основні функції системи: 
  - Система має мати списки, віртуальну чергу, можливість швидкої консультації, та календар записів. 
  - Списки мають формувати зручний доступ до лікарів та пацієнтів. 
  - Віртуальна черга має включати послідовний запис та виклик до лікарів.
  - Калдар повинен включати розклад прийому та відпустки лікарів.
  - Для швикої консультації, можна надати доступ до наразі вільних лікарів, які зможуть дати швидку пораду, без потреби чекати в черзі або йти в лікарню.

### 3. Для кого цей продукт:
Ця система призначена для спрощення системи прийому до лікаря. Для зменшення числа людей та натовпу в лікарні.
