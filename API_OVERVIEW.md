# Система запису до лікаря

## Приклад технічної документації

### 1. Отримати список лікарів

Endpoint
`GET /doctors`
Опис
Повертає список доступних лікарів. 

Приклад запиту
`GET https://api.medbook.example/v1/doctors`

Приклад успішної відповіді (200)
```
{
    "doctors": [
    {
      "id": 1,
      "name": "Іваненко Олена",
      "specialty": "Терапевт"
    },
    {
      "id": 2,
      "name": "Петренко Андрій",
      "specialty": "Кардіолог"
    }
  ]
}
```

### 2. Створити запис до лікаря

Endpoint `POST /appointments`

Опис
Створює новий запис пацієнта до лікаря.

Приклад запиту
```
{
  "doctor_id": 2,
  "date": "2025-06-20",
  "time": "10:30",
  "patient_name": "Польщенко Нікіта"
}
```
Приклад успішної відповіді (201)
```
{
  "appointment_id": 145,
  "status": "confirmed",
  "message": "Запис успішно створено"
}
```

### 3. Отримати інформацію про запис

Endpoint `GET /appointments/{id}`

Опис
Повертає інформацію про конкретний запис до лікаря.

Приклад запиту
`
GET https://api.medbook.example/v1/appointments/145
`

Приклад успішної відповіді (200)
```
{
  "appointment_id": 145,
  "doctor": "Петренко Андрій",
  "specialty": "Кардіолог",
  "date": "2025-06-20",
  "time": "10:30",
  "status": "confirmed"
}
```

### 4. Коди відповідей та помилок
| Код | Опис |
|-----------|-------------|
| 200 | Успішний запит |
| 201 | Ресурс успішно створено |
| 400 | Некоректний запит |
| 401 | Користувач не авторизований |
| 404 | Ресурс не знайдено |
| 500 | Внутрішня помилка сервера |
